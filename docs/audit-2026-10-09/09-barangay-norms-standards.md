# Audit 09 - Barangay norms and standards (web system)

Date: 2026-10-09. Read-only review; no existing file was edited. Lens: does the web system follow norms that apply to a Philippine barangay, and where does the design assume things a real barangay would not do.

Evidence labels: VERIFIED = read in a primary source this session (fetched through a summarising tool, so the wording is paraphrase, not a character-exact read); SECONDARY = from a search snippet or commentary; FROM MEMORY = my own recollection, not checked this session. No circular number or deadline below is invented; where a source could not be read it says so.

Severity: P0 legal/safety exposure, P1 wrong or misleading, P2 friction, P3 polish. Effort S/M/L.

## What fits well

- Cross-tenant 404, server-side role checks, audit metadata of ids only, raw narrative limited to the records custodian: consistent with the Code's custodian role and DPA Sec 11/20.
- Not duplicating DILG BIMSS/KPIS; blotter and Lupon stay in binders; the referral log shows no names or narratives.
- Refer-not-handle for PNP, BFP, EMS matches MC 2026-037's refer-immediately language (SECONDARY).
- No per-tanod response-time ranking or leaderboard in the web pages (grep found none): the metric is aggregate.
- Paper-is-official-record (paper signatures, scans, record-from-paper) matches how barangays sign and how auditors review.
- SMS broadcast list records consent source and keeps purpose separation.
- SOS has a device-local SMS fallback independent of the workstation; skip link and labelled login present.
