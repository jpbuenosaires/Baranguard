## What is solid
- Wiring script and jsdom suite are green with real counts (779/0 and 625/0, zero skipped).
- No web call targets a nonexistent route or wrong method; request/response key names agree with the controllers for every endpoint compared.
- UTC revival at the response boundary (apiClient.js:204-210, mirrored in both secondary clients) is correct and unit-tested; page-size caps never exceed 100.
- Polling hygiene: main.js stops the previous page's handle before each boot (main.js:88-92); dispatch-center, gis, service-health, sms-monitor clear their intervals; AppShell's poller and keydown/global-search listeners self-remove when the shell is detached (AppShell.js:679-681, 1433-1456); modal keydown handlers pair add/remove.
- Cross-role routing: PAGE_ROLES gating plus a role-aware landing page works; tanod/lupon get a clear dead-end page with Sign out; detail pages without a param fall back.
- Newer workflow code (approvals, school zones, accomplishment, referral log) uses Manila-pinned formatting and escapeHtml; no unescaped `innerHTML` sites spotted in the pages read (not an exhaustive review of all 57 modules).
- Network failure and non-JSON responses map to typed `ApiClientError`s with retry states.

## Could not verify
- Actual runtime behaviour in a browser (servers not started per instructions); all findings are from source reading plus the two existing test suites.
- Whether every page's four states (loading/empty/error/populated) are really present - only spot-read.
- Complete `innerHTML` interpolation review of every page (Rule in REFERENCE.md §6); only incidental reads.
- Exact request-body field names for each POST/PATCH against each controller's validator beyond the ~20 key endpoints (list/read mappers compared, write bodies compared for shifts, dispatch, dispatch-offers, availability review only by reading names, not by executing).
- Whether `GET /school-checkins` omission is intentional.
- Whether Windows/locale of the workstation is actually Asia/Manila (F-12 impact depends on it).
- Flakiness: the suite ran once; the documented order-sensitive map test passed this time.
