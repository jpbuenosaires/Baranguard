# 07 - Web client security and privacy audit (2026-10-09)

Scope: `web/` (vanilla JS dashboard) and its contract with `backend/`. Read-only audit; no requests were sent to any live host. Method: full-text sweep of every `innerHTML` / `outerHTML` / `insertAdjacentHTML` / `document.write` site in `web/src` (43 files), a script that listed every `${...}` interpolation not wrapped in `escapeHtml(...)` (1,224 raw hits, triaged by expression name and then by reading the surrounding code), plus a route-by-route comparison of `PAGE_ROLES` against `AuthMiddleware::requireRole` in the controllers.

## What is solid

- **JWT is in memory only** (`apiClient.js:62-95`): never in `localStorage`/`sessionStorage`, no cookie, no refresh token; logout clears it and calls `POST /auth/logout`; a 401 clears it. No service worker or Cache Storage use found (`grep` empty).
- **`escapeHtml` is complete** (`utils/escapeHtml.js`: `& < > " '`, null-safe) and used consistently in all print layouts and most card renderers; most pages build with `textContent` or DOM helpers. No dangerous sink APIs beyond `innerHTML`.
- **Server enforces role on every route I sampled** (about 70 handlers across 25 controllers); cross-tenant scoping is by `barangay_id` in the queries I read. All `PAGE_ROLES` entries are equal to or narrower than the server role lists, except the PB cases in V-02. Raw narrative and party fields are returned only to the Secretary (`IncidentsController.php:625-640`) and the view is audited (`raw_narrative_viewed`).
- Admin-only server routes confirmed for audit log, SMS (all 9 handlers), system health, settings, user list and create, map-package upload, dispatch create and cancel, fatigue acknowledge.
- CSV formula injection guarded (`DataTable.js:321`). Evidence and scans downloads use `nosniff`, filename sanitising and `Content-Disposition`.
- External links open with `rel="noopener noreferrer"`; no secrets, API keys or internal tokens are embedded in `index.html` or the JS (only the tunnel hostnames, which are public).
- No `console.log` of data (only one `console.warn` for map init failure, `citizen-reports-inbox.js:552`).
- Public citizen POST was removed (405), which closes an unauthenticated write surface.

## Could not verify

- Whether `letterheadHtml()` (used in `school-zones.js` and `statistical-reports.js` print layouts) escapes every field it receives; I did not open its definition.
- Whether the server honours `Idempotency-Key` on endpoints where the web client does not send one (V-08), and whether wrapper callers outside `apiClient.js` add keys.
- The exact content of inbound citizen SMS (whether it can equal narrative text), so V-14 is a question, not a confirmed leak.
- Live response headers from Apache for `web/` and `:8081` (no `Header` directives were found in the repo, but `C:\xampp\apache\conf` is outside it); CSP and header findings are based on the repo only.
- Whether the retention statement exists in `docs/PRIVACY_NOTICES.md` in a form suitable for the UI (not read).
- Whether the `fatigue-flags.js` module is imported anywhere at runtime (I found no mount in `main.js`).
- Browser behaviour of any finding: nothing was run or tested in a browser; all results are from code reading.
