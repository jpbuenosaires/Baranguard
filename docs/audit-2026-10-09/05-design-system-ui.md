# 05 - Design system and UI consistency audit (web/)

Date: 2026-10-09. Lens: visual/UI consistency and design-system compliance across `web/css` (base.css + 15 component + 18 page stylesheets, 95 files in css/src) and `web/src`. Read-only audit; no existing file was edited. Contrast ratios were computed with a throwaway script (scratchpad, not in repo) from the token values in `web/css/base.css:98-205` (light) and `base.css:316-348` (dark palette, `--dark-*`); tints that are `color-mix()` were reproduced by linear sRGB mixing over the stated ground.

Severity: P0 unusable/unsafe, P1 wrong or misleading, P2 friction, P3 polish. Effort: S/M/L.

Method note: the dev server did not answer (`curl http://localhost/baranguard/web/` returned 000), so NOTHING here was verified in a browser; all findings are from reading CSS/JS and computed contrast. Layout overflow claims are computed from CSS values and marked as such.

## What is solid

- Token architecture in `base.css`: single dark palette (`--dark-*`) remapped in two blocks, theme stamp in `index.html:16-58` guarantees `[data-theme]` always exists, so page-level dark rules work in every dark state.
- The audited text/fill token families (`*-solid`, `*-text`, `--pill-*-text`, role badges at 8%) are mathematically sound where they are actually used: all 4.5:1 or better in both themes (see table).
- Print sheet palette is theme-independent (`--sheet-ink/-muted/-border`, incident-detail.css:812-815, tanod-workflow.css Printed forms), so dark-mode printing is legible; `print-color-adjust: exact` set.
- `tanod-workflow.css` (the newest 396-line stylesheet) is 100% token-clean: zero hex, zero rgba, spacing/type via tokens, intrinsic `auto-fit/minmax` grids.
- Pages with zero literal hex: personnel, settings, sms-monitor, service-health, map-packages, incident-management, citizen-reports, referral-log, school-zones, accomplishment-reports, approvals, tanod-workflow (CSS only; JS exceptions in D-12).
- `prefers-reduced-motion` handled in 18 blocks; skip link exists (`base.css:566`); `AsyncState` uses `role=status/alert`; `DataTable` wrap scrolls horizontally rather than overflowing the page; sidebar becomes a drawer with scrim at 768px; spacing 77% tokenised, radius 80% tokenised.
- Shared `.status-pill`, `.filter-chip`, `.stat-card-grid`, `.role-badge` and `.page-tabs` are well specified; the problem is adoption (D-18), not design.
