# Audit 01 - Admin (Chief Tanod / desk officer) web screens

Date: 2026-10-09. Scope: dashboard, dispatch-center, incident-management, incident-detail, gis-live-tracking, citizen-inbox, analytics (reports tab), settings, sms-log, audit-log, service-health, map-packages, plus the shared AppShell alarm path. Method: read each page file and the handler/route behind each control. `node web/scripts/verify-web-wiring.mjs`: 779 passed, 0 failed. Nothing was run in a browser; nothing was modified.

Severity: P0 blocks safe use, P1 wrong or misleading, P2 friction, P3 polish. No P0 found: the SOS alarm path (bell + chime + dispatch banner) works end to end, but several P1 items weaken it.

## What is solid

- Global SOS path exists on every page: 15 s notification poll, chime on new `sos`/`priority_alert` (`AppShell.js:1279-1286, 1433`), bell with unread count, click goes to Dispatch.
- Dispatch Center: 15 s poll with cleanup (`stopPolling`), live-ticking elapsed times, SOS banner with locate/resolve, grouped multi-responder cards, nearest-first tanod picker with honest "location unknown / last fix N min old" (`DispatchAction.js:60-124`), mandatory-reason cancel allowed from `arrived`, and a "no published shift" override flow that reuses the idempotency key.
- Destructive actions are confirmed: SOS resolve, incident resolve (with reason when no dispatch), dispatch cancel (reason), lifecycle changes, SMS broadcast (danger dialog), broadcast offer cancel.
- Four data states (loading / empty / error with retry / populated) are present on Dashboard, Dispatch (first load), Incident Management, Citizen Inbox, Incident Detail, Audit Log, Service Health, Map Packages, Settings system cards, Analytics.
- Role gating is consistent with the reference: Admin-only controls are hidden for Secretary (`incident-management.js:951-957`), narrative restricted text (`incident-detail.js:363-365`), PB roster skip (`admin-dashboard.js:397-400`).
- Service Health separates `healthy / unhealthy / not_configured` and keeps not-configured neutral; Audit Log has no edit/delete controls; Advisory List is consent-driven.
- Output escaping: server data goes through `textContent` or `escapeHtml` at the interpolation sites read (audit of every site not exhaustive).
- Wiring script: 779 passed, 0 failed.
