F2. Session steps (about one visit per barangay)

  1. Pilot first. Run the whole session once with 2 people who are not on the team (not tanods from the study). Time it. Ask what words confused them and fix those words before the real sessions.
  2. Reset the demo data before each tester (double-click Reset UAT Data.bat, about one minute). Start the session within 9 hours of the reset, or the shift-based tasks fail for a data reason and not a defect.
  3. Say the same welcome to everyone (read aloud, in English or Filipino): "We are testing the system, not you. If something is hard, the system needs fixing. You can stop any time. Please do the steps yourself. I will only watch and write."
    "Ang sistema ang sinusubok namin, hindi kayo. Kung may mahirap, ang sistema ang aayusin. Maaari kayong huminto anumang oras. Kayo mismo ang gagawa; manonood at magsusulat lang ako."
  4. Consent and Part 2, then the core tasks for the tester's role (F3), then Parts 3, 4 and 5. Give the account password separately; never write it on a form.
  5. Write the seconds taken and the number of errors or help requests for each task. Do not help unless the tester asks; each help counts as one.
  6. If a task fails, write a Defect ID and log it in the defect log of 04-uat-signoff.html (Part H). Use the severity words of that form (Critical, Major, Minor).
